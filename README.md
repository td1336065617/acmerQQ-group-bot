# acmerQQ群机器人 · acmer_qq_group_bot

> 面向 ACM/ICPC 竞赛群的比赛信息查询与推送机器人：牛客 / Codeforces / AtCoder / 洛谷赛程一站查，四平台账号绑定与战绩卡，群排行与每日早报。

```text
牛客 / Codeforces / AtCoder / 洛谷 公开接口
XCPC Link（线下赛）
              │
              ▼
        统一 Contest 模型（北京时间）
              │
      ┌───────┼────────────────────────┐
      ▼       ▼                        ▼
  查询指令   账号/战绩       定时推送（每 30 秒检查）
  最近比赛   绑定与排行       每日早报（默认 08:00）
  各平台赛程 战绩卡/进步榜    赛前 15 分钟提醒
              │
              ▼
   自适应输出：短内容发文字，长内容转 PNG 图片
```

- **支持平台**：`qq_official` / `qq_official_webhook`（QQ 官方）+ `aiocqhttp`（OneBot v11）
- **运行要求**：AstrBot `>=4.13.0,<5`；版本号与更新内容见 [CHANGELOG.md](CHANGELOG.md)
- **许可**：MIT

## 功能

### 🏁 比赛查询
- 一条 `最近比赛` 汇总牛客、Codeforces、AtCoder、洛谷与 XCPC 线下赛未来 N 天内及正在进行中的比赛，按开始时间统一排序。
- 每个平台各有“全部未开始比赛”与“最近一场比赛”两类指令，赛程带名称、北京时间、时长与链接。
- 线下赛查询只保留 ICPC/CCPC 等线下赛事并自动过滤网络赛，结果中标注实际数据源（`xcpc.link`，备用 `xcpc.ink`）。
- 长列表自动转成 PNG 图片发送，短结果仍发文字。

### ⏰ 定时推送
- 每日早报：默认 08:00（北京时间），推送当天开始的已启用平台比赛；当天没有比赛时不发正文。
- 早报附带「本周进步榜」与「本周退步榜」两张图片（各平台前 5 名），没有比赛时只推榜单。
- 赛前 15 分钟提醒：按“平台 + 比赛 ID”去重，每个启用群各收一次。
- 群训练周报：默认每周一 20:00 推送「本周进步榜 / 退步榜」两张卡 + 文字统计（参与人数、人均活跃天数与提交数、进步/退步最多），同一 ISO 周每群只推一次，无数据时静默跳过。
- 报名截止提醒：牛客比赛报名截止前 24 小时与 2 小时各提醒一次（全局幂等，只发给推送平台含牛客的群）。
- 主动推送依赖该群先与机器人产生过消息；`acmer激活` 可显式激活一次，重启后群内任意消息会自动恢复。

### 🔗 账号绑定与战绩
- 后台「账号绑定」可新增 / 编辑 / 删除：**编辑时平台与 QQ 用户 ID 不可改**（要换请删除后新增，删除不影响群成员资格）；账号未变更时只改昵称**不会重新校验**，平台抖动也能保存；**归属群只在新增时设置**（＝普通加入，用户之后可自行「退出排行」），要“强制且留痕”的成员请用「群排行 → 排行成员」。
- 四平台账号绑定，全部通过公开资料字段校验，**不需要平台密码、Cookie 或 API Key**：Codeforces 姓氏、牛客个性签名、洛谷个人介绍、AtCoder Affiliation。
- 验证码 10 分钟有效、成功后立即失效、只保存哈希，建议在私聊中完成绑定。
- `我的账号` / `我的战绩` 出四平台总览卡，`我的cf`、`我的牛客`、`我的洛谷`、`我的atcoder` 出单平台卡；群聊中附带自己在对应平台的本群排行。
- 战绩卡包含最近 Rating 趋势折线图、Codeforces 通过题难度分布、题目级分析摘要与头像缩略图；Codeforces / AtCoder 另有近 12 个月打卡热力图。
- `查询cf` / `查询atcoder` / `查询牛客` / `查询洛谷` 可直接查**未绑定用户**的资料卡；加「详细」后缀才抓难度分布与分析。

### 🏆 群排行
- 后台可**强制把已绑定用户加入**某个群的排行（群排行页 →「排行成员」）；强制加入不受用户自己「退出排行」影响，移除只去掉强制标记。
- `群排行` 给出四平台前 5 名总览；`群cf排行` 等平台排行每页 30 人并可翻页。
- `本周进步榜` / `本周退步榜` 展示各平台近 7 日 Rating 上升 / 下降最多的成员。
- 绑定成功会自动加入发起绑定群的排行；`加入群排行` / `退出群排行` 可随时调整。

### 📖 插件介绍

根目录附带 `intro.md`：安装「菜单导航」插件后，发送 `插件介绍` 可看到本插件的完整功能清单
（含每日早报、赛前提醒、赛后赛果、训练周报、报名截止提醒这类**无需指令的主动推送**），
`插件介绍 acmer` 可只看本插件。

### 🏅 平台排名口径

资料卡与排行卡会显示成员在各平台的**平台内排名**（如「平台排名 #420 · Top 0.31%」）：

| 平台 | 数据源 | 实时性 |
| --- | --- | --- |
| Codeforces | 官方全站榜单 `user.ratedList` | **周期快照**，展示为「（榜单快照）」；榜单里的 rating 会滞后于实时（实测同一人实时 3857 / 榜单 3650），名次可能与官网略有差异 |
| AtCoder | 用户页 Rank 行 | 实时（含平台给出的 Top x%） |
| 牛客 | 个人页 / rating-basic 接口的 Rating排名 | 实时 |
| 洛谷 | 用户接口的 ranking 字段 | 实时 |

> CF 之所以用榜单快照：它是唯一能批量拿到全站排名的公开接口；官网实时名次需要逐页抓取，既慢又易失效。
> 榜单在插件启动时后台预热（十万级数据，首次约 2 分钟），之后 24 小时走缓存。

### ⚙️ WebUI 配置
- AstrBot 管理面板 → 插件管理 → **acmerQQ群机器人**：管理员列表、每日早报时间、推送平台、赛前提醒开关、最近比赛天数、**牛客赛事范围**、文字转图片阈值、@全体成员尝试开关。
  - 「牛客赛事范围」默认 `全部牛客赛事`：除牛客系列赛外，也包含高校校赛 / 新生赛同步赛 / 集训营 / 自主创建赛；想只看系列赛可切到 `仅牛客系列赛`（等价于旧口径）。口径只影响展示与推送，抓取始终取全量，切换后立即生效。
- 群列表（收到过消息的群自动注册）：逐群开关推送、覆盖早报时间、设置推送平台与提醒开关。
- 「测试推送」按钮可立即向指定群发一次今日早报，用于验证主动推送链路。

## 安装与快速开始

1. AstrBot 版本需满足 `>=4.13.0,<5`，且已启用 **QQ 官方机器人**（`qq_official` / `qq_official_webhook`）或 **OneBot v11**（`aiocqhttp`）适配器之一，并能正常收发消息。
2. 在 AstrBot 插件页填入仓库地址安装，或把 `metadata.yaml`、`main.py`、`requirements.txt`、`src/`、`pages/` 放入 `AstrBot/data/plugins/acmer_qq_group_bot/`，然后在 WebUI 插件管理页启用并重载插件。
3. 在群里发一条消息完成本群自动注册，再按下面步骤配置。

**首次配置（建议 4 步）**

| 步骤 | 操作 |
| --- | --- |
| 1 | 绑定账号：发送 `绑定cf <用户名>`、`绑定牛客 <用户ID>`、`绑定洛谷 <UID>`、`绑定atcoder <用户名>`，把验证码追加到对应公开资料字段后发送 `确认绑定cf` 等完成绑定（建议私聊进行） |
| 2 | 配置推送时间：WebUI 中设置每日早报时间（默认 `08:00`）、推送平台与赛前提醒开关；需要单独设置的群再在群列表里覆盖 |
| 3 | 配置管理员：适配器不会把群角色映射为 AstrBot 管理员，需在 WebUI「管理员设置」里显式填入用户 ID（QQ 官方填 openid，OneBot 填 QQ 号），否则 `update` 会提示“此指令仅限管理员” |
| 4 | 测试推送：先让目标群给机器人发一条消息，再点群配置里的「测试推送」；若提示“会话未就绪”，让群内再发一条消息或发送 `acmer激活` 后重试 |

## 指令

指令为**全匹配**：消息必须与指令完全一致才会触发，因此“牛客xxxx”之类的聊天内容不会误触发；也可带 `/` 前缀（如 `/nk比赛`），英文指令忽略大小写。

### 🏁 比赛查询（所有人）

| 指令 | 说明 |
| --- | --- |
| `最近比赛`（`近期比赛`） | 汇总牛客 / Codeforces / AtCoder / 洛谷 / XCPC 线下赛未来 N 天内及进行中的比赛 |
| `nk比赛`（`牛客比赛`） | 牛客全部未开始比赛（范围由 WebUI「牛客赛事范围」决定，默认含高校校赛等） |
| `最近nk比赛`（`最近牛客比赛`） | 牛客最近一场比赛 |
| `cf比赛`（`Codeforces比赛`） | Codeforces 全部未开始比赛 |
| `最近cf比赛`（`最近Codeforces比赛`） | Codeforces 最近一场比赛 |
| `atc比赛`（`AtCoder比赛`） | AtCoder 全部未开始比赛 |
| `最近atc比赛`（`最近AtCoder比赛`） | AtCoder 最近一场比赛 |
| `lg比赛`（`洛谷比赛`） | 洛谷全部未开始比赛 |
| `最近lg比赛`（`最近洛谷比赛`） | 洛谷最近一场比赛 |
| `线下赛`（`线下比赛`、`XCPC线下赛`） | XCPC Link 已收录的线下赛程，并标注数据源 |

### 🔗 账号绑定（所有人）

| 指令 | 说明 |
| --- | --- |
| `绑定cf <用户名>` / `绑定牛客 <用户ID>` / `绑定洛谷 <UID>` / `绑定atcoder <用户名>` | 发起绑定，返回需追加到公开资料字段的验证码 |

### 📊 个人战绩（所有人）

| 指令 | 说明 |
| --- | --- |
| `我的账号` / `我的战绩` | 四平台总览战绩卡；群聊中显示本群排行 |
| `刷新我的战绩` | 忽略缓存重新拉取资料 |
| `我的cf` / `我的牛客` / `我的洛谷` / `我的atcoder` | 单个平台战绩卡；群聊中显示本群排行 |
| `@某人 战绩` / `@某人 查询战绩` | 查询被 @ 成员的战绩卡，群聊只读，不改变对方的排行状态 |

| `查询牛客 <数字UID>` / `查询洛谷 <数字UID>` | 查询未绑定用户的资料卡，仅支持数字 UID 或主页链接 |

| --- | --- |
| `群排行` | 四平台排行前 5 名总览 |
| `群cf排行` / `群牛客排行` / `群洛谷排行` / `群atcoder排行` | 平台排行，每页 30 人；可写 `群cf排行 2` 或 `群cf排行第2页` 翻页 |
| `本周进步榜` | 各平台近 7 日 Rating 上升最多的成员 |
| `本周退步榜`（`本周掉分榜`、`退步榜`） | 各平台近 7 日 Rating 下降最多的成员 |

### ⚙️ 推送与菜单（所有人）

| 指令 | 说明 |
| --- | --- |
| `acmer激活` | 首次激活本群主动推送；重启后群内任意消息会自动恢复，重复发送静默忽略 |
| `acmer群管理插件菜单`（`acm菜单`、`比赛帮助`） | 显示功能菜单 |

### 🌙 管理员

> 管理员 = WebUI「管理员设置」里录入的 `admin_users`。**QQ 群主 / 群管理员身份不构成管理员权限**，
> 未录入者一律提示“此指令仅限管理员”。

| 指令 | 说明 |
| --- | --- |
| `update`（`刷新比赛`） | 强制刷新全部比赛数据（绕过缓存） |
| `@某人 绑定cf/牛客/洛谷/atcoder <账号>` | 管理员代绑定：把账号直接绑到被 @ 的成员名下（跳过验证码，自动加入本群排行） |

> ⚠️ 这里的 `@` 必须是**真正的成员 @**（用 QQ 输入框从成员列表选择）；手打 `@昵称` 只是普通文字，拿不到对方 ID，会收到提示。

## 配置

配置入口：AstrBot 管理面板 → 插件管理 → **acmerQQ群机器人**（`pages/settings/index.html`）。配置保存在 AstrBot 的插件 KV 存储中，不在插件目录写文件，升级或重装插件不会丢配置。完整说明见 [docs/CONFIG.md](docs/CONFIG.md)。

后台共 7 个分区：**概览与状态、基础设置、推送设置、群推送配置、账号绑定、群排行、配置备份**。其中：

- **账号绑定**（增删改查）：后台可直接新增 / 换绑 / 删除绑定。与群内 `@某人 绑定cf` 写的是同一份数据，同样跳过验证码，同样受“同一 OJ 账号全局唯一”约束（不会顶掉别人的账号）；保存 / 删除后立即失效群排行缓存。
- **群排行**：只读查看；默认命中本地快照，不触发全群抓取，点“刷新”才强制重算。
- **运行状态 + 立即试跑**：可看最近推送结果与下次推送时间；试跑只针对单群，且**不写幂等键**，因此不会影响当天正式推送。
- **配置备份**：导出 / 导入 JSON；导入会先校验并预览差异，确认后才写入。

**全局配置**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 管理员列表 `admin_users` | `[]` | 可执行 `update` 的用户 openid 列表 |
| 每日早报时间 `settings.morning_push_time` | `08:00` | `HH:MM` 24 小时制，使用北京时间 |
| 推送平台 `settings.push_platforms` | 四平台全选 | 早报与提醒使用的平台 |
| 赛前提醒 `settings.reminder_enabled` | 开 | 比赛开始前 15 分钟提醒 |
| 尝试 @全体成员 `settings.at_all_enabled` | 关 | 通知尝试带 `<@everyone>`，失败自动降级为普通通知 |
| 最近比赛查询天数 `settings.recent_contest_days` | `7` | `最近比赛` 查看未来几天，范围 1～30 |
| 早报附今日一题 `settings.daily_problem_enabled` | 开 | 早报末尾附一道题（`每日一题` 指令同源，只展示题目名与链接） |
| 每日一题平台 `settings.daily_problem_platform` | `nowcoder` | 牛客（本地索引）/ Codeforces / AtCoder / 洛谷 |
| 推荐补题 `settings.recommend_enabled` | 开 | 详细资料卡之后推荐 3 道未通过题 |
| 赛后赛果推送 `settings.settle_push_enabled` | 开 | 比赛结束后推送名次卡（名次/通过题数/参赛人数） |
| 赛后推送延迟 `settings.settle_delay_minutes` | `10` | 赛后多少分钟推送，范围 1～60 |
| 最少参赛人数 `settings.settle_min_participants` | `1` | 低于该人数不推送，范围 1～10 |
| 附带未通过题目 `settings.settle_show_unsolved` | 开 | 仅 Codeforces 有效 |
| 群训练周报 `settings.weekly_report_enabled` | 开 | 每周一次推「进步榜/退步榜」两张卡 + 文字统计 |
| 周报推送星期 `settings.weekly_report_weekday` | `1` | `1`～`7`（周一=1），默认周一 |
| 周报推送时间 `settings.weekly_report_time` | `20:00` | `HH:MM` 24 小时制（北京时间） |
| 文字转图片最大字符数 `settings.max_plain_text_chars` | `1800` | 范围 200～10000 |
| 文字转图片最大行数 `settings.max_plain_text_lines` | `36` | 范围 10～200；与字符数任一超限即转图 |

**按群配置**

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `groups[].enabled` | 开 | 是否向该群推送 |
| `groups[].morning_push_time` | `08:00` | 覆盖全局早报时间 |
| `groups[].push_platforms` | 全部 | 早报实际取“全局 ∩ 群”的平台 |
| `groups[].reminder_enabled` | 开 | 该群是否发送赛前提醒 |
| `groups[].settle_push_enabled` | 开 | 该群是否推送赛后赛果 |

**环境变量（可选，仅用于排障）**

| 变量 | 说明 |
| --- | --- |
| `ACMER_QQ_BOT_FONT` / `ACMER_QQ_BOT_FONT_INDEX` | 覆盖转图使用的中文字体文件与 TTC 字体面索引 |
| `ACMER_QQ_BOT_EMOJI_FONT` / `ACMER_QQ_BOT_EMOJI_FONT_INDEX` | 覆盖 Emoji 字体路径与字体面索引 |
| `ACMER_STORE_BACKEND` / `ACMER_STORE_DIR` / `ACMER_DUAL_WRITE_KV` | 账号存储后端（`sqlite`/`kv`）、存储目录与 KV 双写开关 |

## 数据来源

赛程与账号数据全部来自公开接口或页面，**不要求用户提供平台密码、Cookie 或 API Key**。

| 平台 | 来源 | 说明 |
| --- | --- | --- |
| Codeforces | `codeforces.com/api/contest.list` | 官方 API，取 `phase=BEFORE` |
| 牛客 | `ac.nowcoder.com/acm/calendar/contest` | 比赛日历接口，抓**当前月及后续 3 个月**；按 `ojName`（OJ 归属）识别牛客赛事，因此高校校赛、新生赛、集训营等同样收录 |
| AtCoder | `atcoder.jp/contests/` | 官网 Upcoming Contests 赛程表 |
| 洛谷 | `luogu.com.cn/contest/list` | 页面内 `#lentille-context` JSON，无需 Cookie |
| 线下赛 | [`xcpc.link`](https://www.xcpc.link/)（备用 [`xcpc.ink`](https://www.xcpc.ink/)） | 首页脚本中的 XCPC/ICPC/CCPC 赛程，仅保留线下赛事 |

账号资料同样来自公开页面：Codeforces 官方 API、牛客公开竞赛主页与练习页、洛谷公开个人页与练习页、AtCoder 公开用户页与 AtCoder Problems 估计难度；Codeforces 做题分布扫描最近最多 50000 条公开提交，AtCoder 与牛客最多 20000 条（牛客为 200 条/页 × 100 页），练习记录受隐私保护时不做强行估算。

牛客的题目难度与知识点来自**题库索引**：插件会整库抓取一次牛客题库列表（约 1.4 万题，索引每周更新、落盘复用），因此难度分布覆盖全部通过题，而不是只覆盖前若干道。少数只存在于比赛中的题目（定制自测题等）牛客未公开难度与知识点，卡片会如实标注为“未标难度”。

**接口抖动时的表现**

- 抓取失败会返回友好提示而不是报错堆栈；若本地还有旧数据，会先用旧数据兜底，因此网站短暂波动不影响查询。
- 平台侧临时限流时，排行结果会说明失败的平台与账号数，这些账号本次不计入排行。

## 常见问题

**比赛没有推送 / 没收到早报**
依次检查：该群是否出现在 WebUI 群列表且已启用；该群在机器人**本次运行期间**是否发过消息（QQ 官方通道的主动推送前提，可先发一条消息或 `acmer激活`；OneBot 通道无此限制）；当天是否有比赛（无比赛时不发正文，只在有榜单数据时推榜单）；全局与群级的早报时间、推送平台、提醒开关是否正确。日志出现 `No cached msg_id ... skip send_by_session` 就是这个前提没满足。

**`update` 提示“此指令仅限管理员”**
适配器不会把群主 / 群管理员角色映射为 AstrBot 管理员，必须到 WebUI「管理员设置」里显式填入用户 ID。QQ 官方填 openid：在群里发一条消息，然后从 AstrBot 日志的 `用户名/OPENID: 消息` 记录里取斜杠前的部分；OneBot 直接填 QQ 号。

**插件装好了、后台能配置，但群内指令没反应**
检查 AstrBot **设置 → 插件配置 → 可用插件**（`plugin_set`）是否包含 `acmer_qq_group_bot`（或设为“全部”），以及该会话级插件开关是否启用；修改后保存并重载插件。另外指令为全匹配，只发送前缀不会触发。

**绑定失败 / 收不到验证码**
验证码要**追加**到平台公开资料字段（Codeforces 姓氏、牛客个性签名、洛谷个人介绍、AtCoder Affiliation）而不是覆盖，字段中包含完整验证码即可通过。洛谷个人介绍为空仍会正常发放验证码，只有字段缺失或页面读取失败时才会阻止发放。验证码 10 分钟有效，过期需重新发起绑定。

**图片发不出来 / 收到的是纯文本**
长消息与战绩卡优先转 PNG 图片，环境里没有 Chromium/Chrome、Firefox、`wkhtmltoimage` 时会回退到 Pillow，渲染失败或超时则自动改为分片文字发送，结果不会丢失。若长期只收到文字，可在日志中查看渲染失败原因，或用 `ACMER_QQ_BOT_FONT` 指定可用的中文字体后重试。

**“最近比赛”少了比赛 / Rating 变化不对**
`最近比赛` 只展示未来 N 天（默认 7 天，可在 WebUI 调至 1～30 天）内开赛或仍在进行的比赛；`本周进步榜` / `本周退步榜` 只统计拥有完整一周快照的成员，缺少历史基线的成员不计入。

**@全体成员没生效**
QQ 官方机器人在群聊场景不支持 `@everyone`（官方格式文档只对文字子频道定义该标签），与机器人是否群管理员无关。插件开启后仍会照常发通知，失败时自动降级为不带 @ 的普通通知，并在该群 6 小时内不再重试；建议在 QQ 官方通道保持关闭。OneBot 通道支持 `@全体成员`（At 段传 all），可正常使用。

## Windows 支持

Windows 上 Chromium / Firefox 通常不在 PATH，插件已内置常见安装路径探测
（Chrome / Edge / Firefox），并内置 Windows 系统字体（微软雅黑 / 黑体 / 宋体 / 等线）
与 Emoji 字体（Segoe UI Emoji）。

若仍拿不到图片，可显式指定（不改代码）：

```bat
set ACMER_QQ_BOT_RENDERER=C:\Program Files\Google\Chrome\Application\chrome.exe
set ACMER_QQ_BOT_FONT=C:\Windows\Fonts\msyh.ttc
set ACMER_QQ_BOT_FONT_INDEX=0
```

> 缓存与数据库位置：`data/plugin_data/acmer_qq_group_bot/`（不再写入插件代码目录）。

## 开发

- 运行时依赖：`aiohttp>=3.9.0`、`pydantic>=2.0.0`、`Pillow>=10.0.0`，以及 AstrBot 4.x 插件运行环境。
- 目录结构：

```text
acmer_qq_group_bot/
├── main.py                 # AstrBot Star 入口：指令分发、推送、WebUI 接口
├── metadata.yaml           # 插件元信息（名称、版本、适配器）
├── requirements.txt
├── src/
│   ├── models.py           # 统一比赛模型、平台定义、北京时间与群配置
│   ├── contest_fetcher.py  # 四平台与 XCPC Link 赛程抓取、缓存与预热
│   ├── output_renderer.py  # 长消息自适应输出（文字 / 图片）
│   ├── account_fetcher.py  # 四平台账号资料与题目级分析
│   ├── account_registry.py # 绑定挑战（验证码哈希）与账号注册
│   ├── account_store.py    # 本地 SQLite 存储（绑定、群成员、快照、缓存）
│   ├── account_cards.py    # 战绩卡与排行卡渲染
│   ├── rank_service.py     # 群排行 / 进步榜快照读模型
│   ├── scheduler.py        # 定时推送：每日早报与赛前 15 分钟提醒
│   └── utils.py            # 带超时与重试的 HTTP 请求、指令规范化等
├── pages/settings/         # WebUI 配置页
├── assets/fonts/           # 内置 Emoji 字体
└── docs/                   # 配置文档与设计说明
```

- **数据存储**：账号、群成员、待确认绑定与 Rating 快照默认存放在本地 SQLite `data/plugin_data/acmer_qq_group_bot/acmer_store.db`；首次启用时会从 AstrBot KV 自动迁移并生成 JSON 备份，默认开启 KV 双写，设置 `ACMER_STORE_BACKEND=kv` 可回退旧模式。缓存与渲染产物放在插件 `data/` 目录下（`contest_cache.json`、`output_cache/`、`account_cards/`），按 500MB 容量做 LRU 清理。
- **新增一个平台的赛程**：在 `src/contest_fetcher.py` 中按现有平台实现抓取方法，把结果转换为 `src/models.py` 的 `Contest` 模型；再在 `src/models.py` 的 `PLATFORM_LABELS` / `DEFAULT_PLATFORMS` 与 `main.py` 的 `QUERY_COMMANDS` 中登记平台标识与指令别名，即可接入查询、早报与提醒。
- 指令与文案以 `main.py` 中的指令表为准（`QUERY_COMMANDS`、`GROUP_RANK_COMMANDS`、`MENU_TEXT` 等），修改后请同步更新本文件与 [docs/CONFIG.md](docs/CONFIG.md)。

### 缓存、预热与重试（工程细节）

- 请求超时 10 秒、最多重试 3 次（间隔递增）。
- 在线比赛缓存 5 分钟、线下赛缓存 30 分钟（持久化到 `data/contest_cache.json`）；缓存过期时同一平台只允许一个请求真正抓取，其余并发查询复用结果。
- 定时任务会在缓存到期前 90 秒预热一个平台；预热失败按平台指数退避（5 分钟起，最长 30 分钟）。
- 账号资料缓存 30 分钟、题目级分析缓存 12 小时、题目资源缓存 24 小时；分析失败用 5 分钟短缓存。
- 群排行 / 进步榜使用本地快照（新鲜窗口 60 分钟 / 2 小时），过期先返回旧数据并后台刷新。
