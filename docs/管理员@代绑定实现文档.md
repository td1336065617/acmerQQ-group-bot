## 0. 硬性口径：这里的“管理员”= 后台录入的 admin_users

**本功能只认 WebUI 后台录入的管理员列表 `admin_users`，绝不包括 QQ 群主 / 群管理员。**

- 唯一判据：`AcmerGroupBot._is_admin(event)`（main.py:586）。它读取插件 KV `admin_users`，
  用 `platform_compat.admin_entry_matches` 匹配 `platform_id:uid` 或裸 uid。
- 适配器即使把群主/群管理员角色放进 `event` / `message_obj.sender.role`，本功能**一律不读、不认**。
- **禁止**新增任何“群角色 → 管理员”的映射；**禁止**用“发送者是群主”之类的判断放行。
- 未命中 `admin_users` 的群主 / 群管理员发送该指令 → 回“此指令仅限管理员”，
  且**不得触发 `get_profile` 抓取，也不得写库**。
- 授权判断必须放在 `_reply_admin_bind` 的**第一行**，先于 `get_profile` 与 `save_binding`。

授权操作方式（同步写进 CONFIG / README）：
WebUI → 插件管理 → **acmerQQ群机器人** → 管理员设置，把操作者加入 `admin_users`
（QQ 官方填 openid，OneBot 填 QQ 号）。

> 依据：main.py 全文没有任何基于群角色的判断，`_update` 也只用 `_is_admin`。
> 本功能沿用同一口径，不引入第二套权限体系。

## 2. 常量与正则（main.py，紧邻 `ACCOUNT_BIND_RE` 之后）

```python
#: 管理员 @代绑定：@ 一个成员 + 绑定指令，跳过验证码直接写入目标名下。
#: 允许显式“代”前缀（@某人 代绑定cf xxx），也允许与自助绑定同词
#: （@某人 绑定cf xxx）——靠“恰好一个非机器人被 @ + 发送者是后台管理员”区分。
ADMIN_BIND_RE = re.compile(
    r"^(?:代\s*)?(?:绑定|bind)\s*(cf|codeforces|nk|牛客|nowcoder|lg|洛谷|luogu|"
    r"atc|atcoder)\s+(.+?)\s*$",
    re.I,
)
ADMIN_BIND_USAGE_RE = re.compile(
    r"^(?:代\s*)?(?:绑定|bind)\s*(cf|codeforces|nk|牛客|nowcoder|lg|洛谷|luogu|"
    r"atc|atcoder)\s*$",
    re.I,
)
```

约束：
- `ACCOUNT_BIND_RE` **保持不动**（自助绑定仍用它）。
- 两个新正则都锚定 `^...$`，**只对剥离 @ 之后的剩余文本**使用（见 §3）。
- 不要为了省事复用 `ACCOUNT_BIND_RE` 而漏掉“代”前缀；平台别名列表与既有保持一致。

## 3. @ 解析重构（行为零变更）

### 3.1 抽出 `_collect_mention_targets`

把 `_mentioned_profile_target` 里“收集被 @ 成员”的整段逻辑原样搬出。
**注意保留原文的 `raw_message` 兜底**（原来第三段是
`content = content or str(raw_message or "")`），否则 OneBot 不解析 mentions 的场景会回归。

```python
@classmethod
def _collect_mention_targets(
    cls, event: AstrMessageEvent, raw_message: str = ""
) -> List[dict]:
    """收集群内被 @ 的成员（去重、排除机器人、排除 @全体）；私聊返回 []。"""
    if not str(event.get_group_id() or "").strip():
        return []

    message_obj = getattr(event, "message_obj", None)
    raw = getattr(message_obj, "raw_message", None)
    mentions = getattr(raw, "mentions", None)
    if isinstance(mentions, dict):
        mentions = list(mentions.values())
    elif not isinstance(mentions, (list, tuple)):
        mentions = []

    targets: List[dict] = []
    seen_ids = set()
    self_ids = cls._self_id_candidates(event, message_obj, raw)
    for mention in mentions:
        if bool(getattr(mention, "is_you", False)):
            continue
        user_id = cls._mention_user_id(mention)
        if not user_id or user_id in seen_ids:
            continue
        if user_id.casefold() in self_ids:
            continue
        seen_ids.add(user_id)
        targets.append(
            {
                "user_id": user_id,
                "display_name": cls._mention_display_name(mention),
            }
        )

    # 某些适配器不把普通 At 放进 raw_message.mentions，兼容 AstrBot 消息链。
    if not targets:
        get_messages = getattr(event, "get_messages", None)
        components = get_messages() if callable(get_messages) else []
        for component in components or []:
            component_type = str(
                getattr(component, "type", "")
            ).casefold()
            if (
                component.__class__.__name__.casefold() != "at"
                and component_type not in {"at", "componenttype.at"}
            ):
                continue
            user_id = cls._mention_user_id(component)
            if not user_id or user_id in seen_ids:
                continue
            if bool(getattr(component, "is_you", False)):
                continue
            if user_id.casefold() in self_ids:
                continue
            seen_ids.add(user_id)
            targets.append(
                {
                    "user_id": user_id,
                    "display_name": cls._mention_display_name(component),
                }
            )

    # 兼容 <@id> / [CQ:at,qq=] 文本格式（原文的 raw_message 兜底必须保留）。
    if not targets:
        content = str(getattr(raw, "content", "") or "")
        content = content or str(raw_message or "")
        for user_id in re.findall(
            r"<@!?([^>]+)>|\[CQ:at,qq=([^,\]]+)",
            content,
            flags=re.I,
        ):
            target_id = next(
                (str(value).strip() for value in user_id if value), ""
            )
            if not target_id or target_id in seen_ids:
                continue
            if target_id.casefold() in self_ids:
                continue
            seen_ids.add(target_id)
            targets.append({"user_id": target_id, "display_name": ""})

    return targets
```

### 3.2 抽出 `_strip_mention_text`

原逻辑在“恰好一个目标”之后统一剥离 @ 文本；保留大小写，不做 casefold。

```python
@staticmethod
def _strip_mention_text(raw_message: str, target: dict) -> str:
    """剥离被 @ 目标的各通道表示，返回剩余文本（保留大小写）。"""
    remaining = str(raw_message or "")
    user_id = str(target.get("user_id") or "")
    if user_id:
        remaining = re.sub(
            rf"<@!?{re.escape(user_id)}>", " ", remaining, flags=re.I
        )
        remaining = re.sub(
            rf"\[CQ:at,qq={re.escape(user_id)}(?:,[^\]]*)?\]",
            " ",
            remaining,
            flags=re.I,
        )
    display_name = str(target.get("display_name") or "").strip()
    if display_name:
        remaining = re.sub(
            rf"@{re.escape(display_name)}", " ", remaining, flags=re.I
        )
    remaining = re.sub(r"\[At:[^\]]+\]", " ", remaining, flags=re.I)
    return re.sub(r"\s+", " ", remaining).strip()
```

### 3.3 改写 `_mentioned_profile_target`（等价）

```python
@classmethod
def _mentioned_profile_target(
    cls, event: AstrMessageEvent, raw_message: str
) -> Optional[dict]:
    """识别“@某人”资料卡查询，要求只有一个非机器人的被 @ 用户。"""
    targets = cls._collect_mention_targets(event, raw_message)
    if len(targets) != 1:
        return None
    command = normalize_command(
        cls._strip_mention_text(raw_message, targets[0])
    )
    if command in SELF_ONLY_PROFILE_COMMANDS:
        return None
    if command not in MENTION_PROFILE_COMMANDS:
        return None
    return targets[0]
```

| `<@target> 绑定cf demo` | None | None |
| 两个被 @ | None | None |
| `@all` | None | None |

## 4. 代绑定识别：`_mentioned_admin_bind`

```python
@classmethod
def _mentioned_admin_bind(
    cls, event: AstrMessageEvent, raw_message: str
) -> Optional[dict]:
    """识别“@某人 绑定/代绑定<平台> <账号>”；非该形态返回 None。"""
    targets = cls._collect_mention_targets(event, raw_message)
    if len(targets) != 1:
        return None
    remaining = cls._strip_mention_text(raw_message, targets[0])

    match = ADMIN_BIND_RE.match(remaining)
    if match:
        platform = normalize_platform(match.group(1))
        if not platform:
            return None
        return {
            "user_id": targets[0]["user_id"],
            "display_name": targets[0]["display_name"],
            "platform": platform,
            "identifier": match.group(2).strip(),
        }

    usage = ADMIN_BIND_USAGE_RE.match(remaining)
    if usage:
        platform = normalize_platform(usage.group(1))
        if not platform:
            return None
        return {
            "user_id": targets[0]["user_id"],
            "display_name": targets[0]["display_name"],
            "platform": platform,
            "identifier": "",  # 触发用法提示
        }
    return None
```

要点：
- **先剥离、后匹配**；绝不拿含 `<@..>` 的原文去匹配（`ACCOUNT_BIND_RE` 锚定 `^` 会直接失配）。
- `identifier` 保留原始大小写，归一化交给 `get_profile†/`normalize_account_identifier`。
- 返回 `None` 时完全交回原有分发，不改变任何既有行为。

## 6. 新增 `_reply_admin_bind`

```python
    async def _reply_admin_bind(self, event: AstrMessageEvent, bind: dict):
        # 授权口径：只认后台 admin_users；QQ 群主/群管理员角色一律不认。
        if not await self._is_admin(event):
            yield event.plain_result("此指令仅限管理员")
            return

        target_user_id = str(bind.get("user_id") or "").strip()
        platform = str(bind.get("platform") or "")
        identifier = str(bind.get("identifier") or "").strip()
        target_display_name = str(bind.get("display_name") or "").strip()
        target_label = (
            f"@{target_display_name}" if target_display_name else "该成员"
        )
        if not target_user_id:
            yield event.plain_result("无法识别被 @ 的成员，请重新发送")
            return
        if platform not in ACCOUNT_PLATFORMS:
            yield event.plain_result("不支持的平台")
            return

        if not identifier:
            command, argument_hint, _ = ACCOUNT_BIND_USAGE_HINTS.get(
                platform, (f"绑定{platform}", "<账号>", "对应公开资料字段")
            )
            sample = ACCOUNT_BIND_EXAMPLES.get(platform, f"{command} <账号>")
            yield event.plain_result(
                f"用法：{target_label} {command} {argument_hint}\n"
                f"例如：{target_label} {sample}"
            )
            return

        group_id = str(event.get_group_id() or "").strip()

        # 1) 抓公开资料（管理员代操作，跳过验证码，故不需要 verification 字段）
        try:
            profile = await self.account_fetcher.get_profile(
                platform, identifier, detail=False, force=True
            )
        except AccountFetchError as exc:
            yield event.plain_result(self._account_error_text(platform, exc))
            return
        except Exception as exc:  # noqa: BLE001 - 抓取异常不能把堆栈抛进群
            logger.warning(
                "管理员代绑定抓取 %s 资料失败：%s",
                platform_label(platform),
                exc,
            )
            yield event.plain_result(self._account_error_text(platform, exc))
            return

        # 2) 读取目标原有绑定，仅用于“已替换”提示
        old_handle = ""
        try:
            accounts = await self.account_registry.get_user_accounts(
                target_user_id
            )
            record = accounts.get(platform)
            if isinstance(record, dict):
                old_handle = str(
                    record.get("handle")
                    or record.get("platform_user_id")
                    or ""
                )
        except Exception as exc:  # noqa: BLE001 - 提示信息失败不影响绑定
            logger.warning(
                "读取 %s 原有绑定失败：%s", target_user_id, exc
            )

        # 3) 原子写入；唯一约束保证不会顶掉别人的账号
        try:
            await self.account_registry.save_binding(
                target_user_id,
                platform,
                profile,
                group_id=group_id or None,
                qq_name=target_display_name,  # ← 必须是被 @ 人的昵称
            )
        except ValueError:
            unbind_command = self._account_bind_command(platform).replace(
                "绑定", "解绑", 1
            )
            yield event.plain_result(
                f"⚠️ 这个{platform_label(platform)}账号已经绑定到其他 QQ 用户，"
                "无法代绑定。\n"
                f"如需变更，请先让原绑定者发送：{unbind_command}"
            )
            return
        except Exception as exc:  # noqa: BLE001 - 存储故障要有用户可见反馈
            logger.error("管理员代绑定保存失败：%s", exc, exc_info=True)
            yield event.plain_result("⚠️ 绑定保存失败，请稍后重试")
            return

        # 4) 缓存与快照（注意：全部针对目标 user_id，不是管理员）
        self._invalidate_all_rank_cache()
        try:
            await self._record_profile_metric(target_user_id, profile)
        except Exception as exc:  # noqa: BLE001 - 快照失败不阻断绑定
            logger.warning(
                "代绑定记录 %s 的评分快照失败：%s", target_user_id, exc
            )

        # 5) 审计日志（不含任何验证码；本功能无验证码）
        logger.info(
            "管理员代绑定成功 admin=%s group=%s target=%s platform=%s handle=%s",
            str(event.get_sender_id() or ""),
            group_id,
            target_user_id,
            platform,
            profile.handle,
        )

        lines = [
            f"✅ 已将 {target_label} 绑定 {platform_label(platform)} 账号 "
            f"{profile.handle}（管理员代绑定）"
        ]
        if old_handle and old_handle.casefold() != str(
            profile.handle or ""
        ).casefold():
            lines.append(f"已替换原有绑定：{old_handle}")
        if group_id:
            lines.append("已自动加入本群竞赛排行。")
        else:
            lines.append(
                "目标在群内发送一次“我的战绩”即可加入该群排行。"
            )
        yield event.plain_result("\n".join(lines))
```

**本函数不调用**：`create_pending` / `get_pending` / `token_matches` /
`_account_verification_value` / `set_user_display_name`。
代绑定是可信路径，不生成验证码、不产生残留 pending 记录。

## 8. 授权测试（必做，直接对应“别让群主乱搞”）

新增用例（放 `tests/test_main_accounts.py`，复用现有 harness）：

1. **群主/群管理员无权限**：`FakeEvent` 发送者 id 不在 `admin_users`，

## 9. 测试用例清单

解析层（`_mentioned_admin_bind`）：
1. QQ 官方 `mentions` + 文本 `绑定cf demo` → target/platform/identifier 正确。
2. 显式 `代绑定cf demo` → 同样命中。
3. AstrBot `At` 组件通道 → 命中。
4. `<@id>` / `[CQ:at,qq=]` 文本通道 → 命中。
5. `@all` → 不命中。
6. 多个被 @ → 不命中。
7. 仅 `@机器人` → 不命中。
8. `@某人 战绩` → `_mentioned_admin_bind` 返回 None（不抢资料卡查询）。

流程层（`_reply_admin_bind`）：
9. 非管理员 → “仅限管理员”，无抓取/无写库。
10. 管理员成功 → `save_binding` 的 `user_id` 是目标、`qq_name` 是**目标昵称**、`group_id` 是当前群。
11. 覆盖场景 → 回复含“已替换”，仍成功。
12. 冲突 `ValueError` → 冲突文案，且**不**调用 `_invalidate_all_rank_cache`（提前 return）。
13. 非法 identifier / 抓取失败 → 各自文案，不调用 `save_binding`。
14. 只 @ 人没写账号 → 用法提示。
15. 私聊 → 不触发代绑定（`_collect_mention_targets` 返回空）。

回归层：
16. 自助绑定三步（`绑定` / `确认绑定` / `解绑`）不受影响。
17. `@某人 战绩` 仍走只读资料卡，不写任何数据。
18. `_mentioned_profile_target` 现有全部用例保持绿。

执行：`pytest tests -q` 全绿；`ruff check --select F,E9` 无新增问题。

## 10. 真机核对（P4）

QQ 官方通道与 OneBot 通道各跑一次：

- `@成员 绑定cf <真实账号>` → 数据落库；目标 `qq_name` 正确；目标进入本群排行；
  排行缓存已刷新（立即查询能看到）；冲突/非法路径文案正确。
- 用**非管理员**账号（含群主）复跑 → 只回“此指令仅限管理员”，库中无变化。

## 11. 边界与防 BUG 复核（实现后逐条打勾）

1. 权限判断在抓取/写库之前。
2. 目标唯一且非机器人；`@all`/多 @/仅 @机器人 不进入。
3. `qq_name` 用被 @ 人昵称，**绝不**用 `_event_display_name(event)`（那是管理员）。
4. 冲突靠原子写的 `ValueError`，不预先 `get_user_accounts` 判冲突（避免 TOCTOU）。
5. 覆盖语义：同目标同平台再次代绑定是覆盖，附“已替换”提示。
6. `group_id` 传当前群会让目标自动进本群排行（含覆盖目标此前“退出排行”，与自助绑定一致）。
7. 绑定后 `_invalidate_all_rank_cache()`。
8. `_record_profile_metric(target_user_id, profile)` 用目标 id。
9. 私聊不误判：私聊 `绑定cf` 仍是本人自绑。
10. 重构零回归：`_mentioned_profile_target` 行为由现有测试锁死。
11. 先剥离 @ 再匹配正则。
12. 账号归一化交给 `get_profile`，不自拼 URL。
13. 所有异常转用户文案，不抛堆栈。
14. 存储故障兜底已由 `save_binding` 内部回退 KV，上层仍 try/except。
15. 幂等：重复代绑定同账号不报错。
16. 正则安全：昵称不进入正则，剥离时 `re.escape`。
17. 日志可审计：admin / group / target / platform / handle；无验证码。
18. 版本口径：不触碰卡片格式/分析缓存，无需提升 `CARD_FORMAT_VERSION`/`ANALYSIS_CACHE_VERSION`。

## 13. 风险与回滚

- **纯新增路径**：`@某人 绑定...` 此前静默丢弃，改后行为可预期；不影响任何既有指令。
- **无数据迁移**：代绑定复用现有 `accounts` 表与唯一约束，写入的记录与自助绑定同构；
  回滚只需回退代码，无需清理数据。
- **风险点**：若误把群角色纳入授权（违反 §0），属于安全缺陷——必须由测试 8-1 拦住。
- 回滚方式：恢复 P1/P2 两个批次的提交即可。

---

> 一句话：授权只认后台 `admin_users`；代绑定只在“恰好 @ 一个非机器人成员”时触发；
> 写入一律走既有原子 `save_binding`，昵称取被 @ 人、快照取目标 id。
