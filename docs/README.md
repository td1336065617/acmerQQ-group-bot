## 三、落位规则

1. 配置相关 → 直接更新 CONFIG.md（不要新开文件）；
2. 流程/条款/案例 → 更新 开发规范.md（§3 强制回填）；
3. 新功能的设计与实现 → 本目录新开 主题-设计文档.md / 主题-实现文档.md，并在本索引「历史设计文档」区登记；
4. 已被实现取代的方案文档：**保留原文**（作为决策依据），但要在本索引里标注「已落地」；
5. 用户可见的功能说明 → 更新 ../README.md；不要另开文件。
